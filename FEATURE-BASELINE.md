## Regression checks

- Compare only the affected code with the baseline using `git diff mobile-studio-feature-baseline-2026-11-17..HEAD -- <paths>`. Keep intentional newer fixes and user-approved changes.
- For canvas, menu, layer, color history, or recovery changes, run the corresponding Qt checks under [tests](tests/) and check the WSL result for the exact Android revision. The watcher reports when its host lacks desktop Qt. The baseline's nine targeted Qt checks passed separately in the local Linux build container under AddressSanitizer.
- When device validation is in scope, prioritize cold launch, New Canvas from Home, all three Color tabs on a narrow screen, Layers **+ → Minimize Layers Panel → icon**, and tap versus swipe in presets and Home. APK inspection and desktop Qt checks establish code and packaging coverage. The first frame, splash timing, and foldable interactions still require Android runtime verification.
